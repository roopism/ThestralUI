# Historical component API depth baseline

This audit records the library on **20 November 2026**, before work on Button, IconButton, Stack and Inline depth. Its counts, declarations, gaps and proposed scenarios describe that snapshot. For the evolving family inventory, use the [component registry](component-inventory.mjs).

Public candidate **0.3.0-rc.1**, reference inventory **2026-11-20.2**. Reviewed 81 existing web families (78 components and three infrastructure families), 135 web value exports and all three native components. The other 18 inventory rows describe planned work, equivalents and exclusions.

The [machine-readable companion](component-depth.json) contains every public entry point, the declaration that supplied it, resolved property names, evidence links and proposed observable acceptance checks. HTML attributes, an arbitrary child, and a headless library re-export have different implications for a design-system consumer. The table links to the current locations of its source, examples and tests. The original paths are recorded in the companion JSON at commit `348685d`. Declaration paths in the JSON resolve from the repository root after `npm ci` and `npm run build:packages`. A declared property tells us what compiles. A repeatable rendered scenario establishes what works. Registry maturity is reported as recorded.

## First two changes proposed at the audit

1. **Button and IconButton.** Add optional `size` with `sm`, `md` or `lg` and `startIcon` / `endIcon` slots to Button. Keep the existing children, default size, two tones, busy behavior, native form button type and forwarded ref. Continue to use `IconButton` with its required label for an icon-only action. Share sizes and square geometry. Exercise RTL logical order and make pictograms decorative by default. Compact styling should preserve the target across size and density settings. Add corresponding native size/slot coverage on the existing native Button and preserve its label. [Material UI Button](https://mui.com/material-ui/react-button/) · [React Native Pressable](https://reactnative.dev/docs/pressable)

2. **Stack and Inline.** Offer `gap` using existing spacing tokens, plus `align`, `justify` and an Inline `wrap` control. An optional map such as `gap={{base: "sm", wide: "lg"}}` should resolve against the parent’s usable width. Verify a wide page containing two panels of different widths, a resized editor retaining focus, and RTL logical start. Simple values preserve existing single-column Stack and wrapping Inline defaults. A minimum typed API avoids arbitrary pixel values and additional layout packages. [Material UI Stack](https://mui.com/material-ui/react-stack/)
