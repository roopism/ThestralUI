# Design system roadmap

The library targets React web and React Native. Foundation work establishes the token modes, theming, localization, accessibility, motion and test contracts shared by each family. Families then qualify in waves covering foundations, actions and feedback, forms, overlays and navigation, collections, organisms, and expressive motion. Native parity follows each family’s integrated web contract.

Read the qualification guide for current counts from the maintainer’s wave tracker and the committed specs, the inventory for family ownership and coverage, and each binding for its open work. [Current qualification](enterprise-checklist.md) · [Family inventory](component-inventory.mjs) · [Family specs](components/)

The release candidate requires zero policy exceptions, a clean integration branch, a passing full gate, verified package archives and a local catalog review. Adoption by consuming applications follows separately. The icon foundation uses the approved Lucide set. [Icon roster and upstream measurements](icon-roster.md)
